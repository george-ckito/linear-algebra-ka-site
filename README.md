# წრფივი ალგებრა მანქანური სწავლებისთვის

ქართული · დამწყები უფროსკლასელები · 30 ანიმაციური სლაიდი · 45-წუთიანი ცოცხალი გაკვეთილი.

ეს არის **Manim Slides**-ით შექმნილი პრეზენტაციის ოფლაინ HTML ექსპორტი. წყაროს კლასები მემკვიდრეობს `manim_slides.Slide`-ს; სლაიდების მეტამონაცემები და ქართული ჩანაწერები ინახება `slides/` საქაღალდეში. HTML ექსპორტს ქმნის Manim Slides-ის Reveal.js კონვერტერი.

## გახსნა

1. ZIP სრულად ამოარქივეთ; საქაღალდეების სტრუქტურა შეინარჩუნეთ.
2. გახსენით **START.cmd** ან **index.html** Chrome/Edge-ში.
3. დააჭირეთ „პრეზენტაციის დაწყება“-ს. **F** რთავს სრულ ეკრანს.
4. **N** ხსნის პირად მომხსენებლის ფანჯარას. ის თქვენს ეკრანზე გადაიტანეთ; აუდიტორიას გაუზიარეთ მხოლოდ პრეზენტაციის ფანჯარა.

საყურებლად ინტერნეტი, Python და დამატებითი ინსტალაცია საჭირო არ არის. თუ ფანჯარა დაიბლოკა, დაუშვით pop-up ან გახსენით `speaker-notes.html`.

## მართვა

- **→ / Space / Page Down**, ანიმაციის დროს: დაასრულებს მიმდინარე ანიმაციას და **ბოლო კადრზე გაჩერდება**.
- **შემდეგი →**: გადავა მომდევნო სლაიდზე და გაუშვებს მის ანიმაციას.
- **← / Page Up**: გადავა წინა სლაიდზე და აჩვენებს მის **ბოლო კადრს**. იმავე სლაიდზე ხელახლა **←** დაჭერით ანიმაცია დაიწყება თავიდან.
- ანიმაციები ავტომატურად თამაშდება **1.3×** სიჩქარით.
- **P**: პაუზა / გაგრძელება. **R**: თავიდან გამეორება.
- **N**: პირადი ჩანაწერები. **F**: სრული ეკრანი.
- **Home / End**: პირველი / ბოლო სლაიდი.
- მაუსი მიიტანეთ ეკრანის ქვედა კიდესთან: გამოჩნდება ღილაკები და სლაიდების არჩევის სია.

დაჭერილი ისარი ავტომატურად არ გადადის რამდენიმე სლაიდზე. ვიდეოს ბუნებრივად დასრულებაც ბოლო კადრზე ჩერდება. ახალი სლაიდის ჩატვირთვისას ჩანს მისი **საწყისი**, და არა საბოლოო კადრი.

45 წუთი მოიცავს ახსნას, გამეორებას, კითხვებსა და სავარჯიშოებს; ეს არ არის 45-წუთიანი გახმოვანებული ვიდეო. ჩანაწერებში მოცემული დროები ჯამში ზუსტად 45:00-ია. სავარჯიშოები: 7, 13, 28; პასუხები: 8, 14, 29.

## ფაილები

- `index.html`, `index_assets/` — Manim Slides-ის ოფლაინ ექსპორტი.
- `slides-controls.js`, `slides.css` — დასრულება/შემდეგი მოქმედება და პრეზენტაციის მართვა.
- `presenter.html`, `speaker-notes.html`, `speaker-notes.md` — ქართული ჩანაწერები, დროის გეგმა და პასუხები.
- `slides/` — Manim Slides-ის 30 სცენის JSON და მედია; `clips/` — დამოუკიდებელი MP4 ფაილები.
- `posters/`, `openings/` — საბოლოო და საწყისი კადრები. საბოლოო კადრები მხოლოდ კერძო წინასწარი ხედისა და სტატიკური ალტერნატივისთვის გამოიყენება.
- `visual_scenes.py`, `linear_algebra.py` — ორიგინალური Manim წყარო.
- `scenes.md`, `design-notes.md` — სრული სცენარი, ვიზუალური სისტემა და რეფერენსების ანალიზი.
- `lesson.json` — შინაარსი და დროები; `generate_docs.py` — ჩანაწერების განახლება.
- `render.py`, `render.ps1`, `build_presentation.py` — რენდერი და Manim Slides ექსპორტი.
- `requirements.txt`, `requirements-lock.txt` — გამოყენებული ვერსიები.
- `fonts/` — Noto Sans Georgian და მისი SIL Open Font License.
- `verification.md` — შემოწმების ანგარიში.

## ხელახალი რენდერი

შემოწმებულია Windows-ზე Python 3.14-ით: **ManimCE 0.21.0 + Manim Slides 5.7.0**. 0.21.0 განზრახაა დაფიქსირებული: 0.22-ის გამომავალი მედიის API შეუთავსებელია Manim Slides 5.7.0-ის რენდერთან.

პაკეტის საქაღალდიდან:

```powershell
.\render.ps1
# სწრაფი 720p ვერსია:
.\render.ps1 -Preview
```

სკრიპტი საჭიროებისას ქმნის პროექტის `.venv`-ს და აყენებს მხოლოდ `requirements.txt`-ის ორ მთავარ პაკეტს მათი აუცილებელი დამოკიდებულებებით. დამატებით არ სჭირდება LaTeX, ManimGL, Qt, ML ბიბლიოთეკები ან ცალკე FFmpeg. ვიდეო იწერება PyAV-ით. ტექსტის რენდერს სჭირდება Windows-ის Cambria/Cambria Math; ქართული შრიფტი დართულია. საყურებლად შრიფტები ვიდეოშია ჩაშენებული.

ცალკეული სცენის შეცვლის შემდეგ, აქტიურ ვირტუალურ გარემოში:

```powershell
python generate_docs.py
python render.py --slides 12 --height 1080
python build_presentation.py
```

რენდერი ინახავს Manim Slides-ის ჩანაწერებს. `build_presentation.py` იყენებს ოფიციალურ `manim-slides convert --offline` ბრძანებას და ქმნის მორგებულ კლავიატურის მართვას. ოფლაინ რესურსების პირველი მიღებისთვის ინტერნეტი საჭიროა; შემდგომი ჩვენებისთვის — არა.

## სასწავლო სიზუსტე

ხილის მონაცემები გამოგონილია. კლასიფიკაციის წესი ხელითაა არჩეული. სწავლა სქემატურად ცვლის bias-ს და არ ასრულებს ოპტიმიზაციას. ქულები არ არის ალბათობები. კვადრატული შეცდომის მაგალითი ცალკე რიცხვით პროგნოზს ეხება. აფინური და წრფივი გარდაქმნების განსხვავება, ერთეულოვანი მიმართულების პროექცია და ახალი მაგალითებით შემოწმება განმარტებულია ჩანაწერებში.

რეფერენსები: 3Blue1Brown-ის წრფივი გარდაქმნებისა და ნეირონული ქსელების ვიზუალური ახსნა; კოდის რეპოზიტორიაში სცენების ორგანიზაციის შესწავლა. მათი კოდი, ვიდეო, პერსონაჟები და ლოგოები არ არის კოპირებული. ბმულები დართულია `scenes.md`-სა და ჩანაწერებში.
